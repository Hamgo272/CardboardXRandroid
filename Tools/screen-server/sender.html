שיתוף המסך למשקפיים

1. לחץ שתף ובחר את כל המסך (לא חלון), כדי שהלחיצות מהמשקפיים ינחתו במקום הנכון.
2. באייפון, פתח את האפליקציה ובחר Computer Screen. הטלפון מוצא את המחשב לבד, כשהם על אותה רשת Wi‑Fi. בפעם הראשונה יופיע כאן כפתור אשר: רק מכשיר שאישרת יכול לראות את המסך ולשלוט בעכבר.
3. השאר את הדף הזה פתוח (אפשר להקטין אותו). הסאונד ממשיך לצאת מהמחשב.
