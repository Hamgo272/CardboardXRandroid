# CLAUDE.md

Fork of brenpoly/CardboardXR (Unity phone-VR app: stereo + lens distortion, ARKit 6DoF,
passthrough, surfaces, MediaPipe hand tracking) being brought to an **iPhone 11** for a
Hebrew-speaking, non-developer user on **Windows with no Mac and no budget**.

- **Read `PLAN.md` first** — goals, hardware deltas, toolchain, phases and acceptance criteria.
  `PLAN_HE.md` is the same plan for the user, in Hebrew.
- Upstream's `README.md` and `KNOWN_ISSUES.md` describe how the app works; keep its structure.
- `Core.unity` is generated by `Assets/Editor/ProjectBootstrap/StereoBuilder.cs` — never edit the
  scene, edit the builder.
- Branch `iphone11`; upstream is the `upstream` remote. iOS bundle id `com.glassesxr.cardboardxr`.
- Unity 6000.6.0f1 with iOS Build Support: `C:\Program Files\Unity\Hub\Editor\6000.6.0f1`.
  Compile-check and run EditMode tests in batch mode before pushing (commands in `PLAN.md`).
- iPhone builds come from `.github/workflows/ios-build.yml` (unsigned `.ipa`); the user installs
  with Sideloadly and a free Apple ID (7-day signing).
- Talk to the user in Hebrew, in short steps. They type their own credentials; never ask for them.
